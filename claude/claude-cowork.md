# Claude Cowork

* 中身は Claude Code とほぼ同じ
  * UIがちがう
  * 機能を絞ってわかりやすくしている

## AIエージェント
* 自律ループ
  * 観察
  * 思考
  * 行動
* ツールを使って行動できる
  * 検索
  * ファイルの読み書き
  * メールの読み書き など

## Coworkの脳
* グローバル指示
* フォルダごとのルール: `CLAUDE.md`

## Coworkの手足
* ファイルの読み書き
* エクセルやパワポを作る
  * PDF,PPTX,xlscx,docxなどを編集可能 
* 検索
* コネクター
  * 外部アプリ

## スキル
* 「脳」と」「手足」を組み合わせた一連の仕事のやり方をパッケージしたもの

## 実演
* 作業フォルダを指定 -> プロンプトを入力
* Claudeが何でもできるので、必要ならバックアップをあらかじめ取っておく

## 能力の拡張
* コネクタ: 外部のアプリと連携

## Skills
* ファイル構造を持つ手順書パッケージ
  * 手順書だけでなく、スクリプトや参考資料も渡せる
* 左のメニュー > カスタマイズ > スキル > 追加 > スキルをアップロード
* 次回からは「ミーティング後の整理をして」というだけで、作業を一気にやってくれるようにする
  * `このミーティング終了後の諸々の作業をスキルにしてください`
